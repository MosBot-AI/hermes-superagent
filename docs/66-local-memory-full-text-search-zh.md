# 本地多词记忆检索

[English](66-local-memory-full-text-search.md) | 简体中文

## 不依赖远程服务的显式搜索

在已获准进入的本地记忆会话中：

```text
/personal-memory search-terms "Shanghai" "Hermes" --limit 10
/personal-memory search-terms "project" "deadline" --include-expired
```

单独激活的 `personal_memory_read` 工具接受 `action: "search_terms"` 和 `terms: ["Shanghai", "Hermes"]`。已有配置、会话、作用域、卸载、worker/cron 及会话结束门槛保持不变。这不会启用自动召回、摄取、新 provider 或新远程接收方。与其他记忆读取一样，返回文本可能进入已有配置的模型/会话历史。

提供 1–8 个不同的字面词，每词 1–128 字符。每个词都必须出现在当前内容或主题中；不同词可以分别匹配不同字段。匹配区分大小写，不进行词干化、规范化、拼音、同义词或身份推断。既有 `search` 与 `recall` 保留原来的字面语义和排序。FTS 运算符、引号、标点和类似通配符的字符都只是字面数据，不是可执行查询语言。

至少三个 Unicode 字符的词使用 SQLite FTS5 区分大小写的 trigram 索引选择候选，然后针对权威记录重新检查全部词。一/二字词使用权威内容的子串检查，包括中文短姓名。只有短词时，扫描最多为现有存储容量 1,000 条记录。这不是中文分词、语义检索或人物消歧实现，不宣称延迟或准确率基准。

结果包含完整权威记录及 ID、revision、来源路径元数据、过期和评估时间。来源标签不证明真实性、原始作者或授权。按创建时间从新到旧返回，默认每页 20 条、最多 50 条；将 `next_cursor` 作为 `after`。分页是实时读取，不是冻结的多页快照。`has_more` 揭示分页截断；上限以记录数计，不是 token 预算。普通搜索排除已过期记录，`--include-expired` 仅是显式检查，不恢复有效性。没有匹配不能证明事实不存在。

## 事务与删除保证

Schema v7 在同一 SQLite 写事务中维护索引、记录、元数据事件和幂等回执。记忆、修正、遗忘以及审核后接受候选共用此路径。索引变更失败会回滚权威修改；精确重试返回原元数据回执，不重新插入历史内容。被遗忘记录是终止状态。搜索把候选行 ID 关联到当前权威记录，在同一读取快照中复查状态、过期时间和每个词。

本切片没有延迟索引任务、后台发布或第二套可写权威。`index_stale: false` 描述受支持写入路径的同步性，不是取证级损坏检测，也不能防止同进程/同 UID 直接篡改数据库。在并发遗忘之前已获准的读取可能返回旧快照；之后的新读取不能检索被遗忘记录。先前模型上下文、历史、导出和备份不能收回。

同时要求 SQLite 的 `PRAGMA secure_delete` 与独立 FTS5 `secure-delete` 配置。修正/移除会删除旧索引文本，而不只是保留 FTS 删除标记。这仍是本地逻辑移除，不保证物理介质、文件系统快照或备份擦除。已过期的 active 记录继续存储并保留索引，在读取时过滤。存储是明文，不是秘密保险库。

## 迁移与兼容性

为获准写入打开精确自有 v1–v6 存储时，原子创建/填充索引并升级到 v7，保留记录、回执和事件。只读 provider/召回打开从不创建或迁移：旧 schema 返回 `readonly_schema_unavailable`，直到显式本地写入器完成升级。不支持运行时降级：旧插件拒绝 v7。升级前按既有隐私/保留策略保存备份；恢复旧备份可能恢复已遗忘内容，本功能不授权该恢复。

SQLite 必须提供 FTS5、trigram tokenizer 和 FTS secure-delete（SQLite 3.42 或更新版本）。不支持的构建会失败关闭，不下载扩展或改变查询语义。会检查精确的虚表/影子表 schema 和 secure-delete 配置。不使用宽松触发器，也不放宽 `trusted_schema`。本次测试的开发解释器为 Python 3.14.9、SQLite 3.53.1，不代表兼容每一种 SQLite 构建或操作系统。

## 验收范围

合成单测与固定宿主契约覆盖中英文混合词、短字符串、标点/查询注入、分页、过期、修改及候选回滚、遗忘后的重启/重放、namespace 拒绝、不迁移的只读访问及已有原生权限门槛。它们不是使用真实个人数据的基准、用户验收或生产部署。Markdown 投影、适配器迁移、自动提取及完整 E2.7 仍是独立工作。
