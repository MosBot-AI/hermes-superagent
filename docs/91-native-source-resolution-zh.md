# 91. 有界原生来源解析

[English](91-native-source-resolution.md) | 简体中文

## 范围与状态

[Issue #123](https://github.com/MosBot-AI/hermes-superagent/issues/123) 为 [43](43-native-checkpoint-boundary-zh.md) 准备的候选加入内部只读解析器。它针对调用方绑定的原生会话，核对保守的仅持久来源子集。这是开发基础，不代表自动摄取、部署验收、新 provider 能力或 E2.8 持久检查点。交付的 provider 仍为 API v1；不改变回调、工具或 provider 配置。

目标为 [Hermes `2281116525106e3c109993ccb5dc74d02bfc1427`](https://github.com/NousResearch/hermes-agent/tree/2281116525106e3c109993ccb5dc74d02bfc1427)。本地固定版本检出提供源码证据。[43](43-native-checkpoint-boundary-zh.md) 的历史固定版本与 [76](76-native-memory-contracts-zh.md) 的 E0.9 核验保留各自范围。

## 调用方持有的绑定

`personal_agent.native_source_resolution.NativeSourceBinding(store, session_id)` 绑定以 `read_only=True` 打开的原生 `SessionDB` 和当前会话。`resolve_checkpoint_sources(evidence, *, binding, expected_revision=None)` 使用该显式绑定。候选字段不能选择数据库路径、其他 profile、其他会话或 SQL 路由。绑定不是远程认证或授权授予；调用方必须已获准读取所选会话。

解析会重新验证准确的候选类型、不可变 tuple 结构、计数和正文摘要，不信任准备对象一定经过安全构造。必须使用公共原生快照一致性操作。在固定版本的只读句柄上，该操作验证 generation，而不是开启固定读取事务。观察到的 `conversation_revision` 私下保存在不可变临时引用中。可选的精确 `expected_revision` 围栏即使在候选文本未变时，也拒绝变化的 revision。两项检查都不将读取与未来压缩提交绑定。

## 保守覆盖与限制

解析器扫描当前会话的全部活动正文，最多读取 256 行及一个溢出哨兵行。局部扫描、扫描溢出及 revision 行数不匹配均关闭式失败。准入上限为每行 16,384 个正文字符、总计 65,536 个字符及 1,024 个逻辑来源身份。不把局部成功或截断当作完整覆盖。

扫描全部活动行，包括工具、摘要和显示行。全局验证每个主逻辑 UID 及被吸收逻辑 UID；扫描会话中任何重复或重叠的身份都会被拒绝。每个扫描正文值必须是字符串或 `None`；字符串必须满足读取后的单行和总正文限制。未知的非文本载荷会使范围不受支持。

只有支持的用户/助手直接正文可被选中。即使没有持久化摘要标志，也会保守拒绝所选文本任意位置的当前或历史摘要标题标记及合并摘要分隔符；因此，逐字引用这些标记也可能被拒绝。工具、摘要、显示及其他不合格行保留为位置屏障：候选及拆分合并不得选中或跨越这些行。所选连续直接正文子集之前或之后的无关不合格行，本身不会导致解析被拒绝。候选覆盖必须是按顺序、无间隙的连续来源行子集；该子集不必覆盖全部活动正文。

支持精确的已持久化单行来源谱系。候选也可使用原生精确的 `\n\n` 拼接核对相邻的普通**用户**行，但这些拆分行不得携带吸收谱系。拆分用户合并也会拒绝原生保留的 `\0json:` 正文前缀；包含该字面前缀的精确单行持久化来源仍然可以合格。助手合并会去除首尾空白并用 `\n` 拼接，因此不支持重建拆分的助手行。待持久化或无身份的合并文本、跨会话身份、缺失行、顺序差异及正文不匹配均会被拒绝，不进行猜测。来源出现位置由逻辑 UID 标识，而非物理行 ID 或仅相同的文本。

原生 `get_messages` 限制返回行数，不限制单行的分配量。读取后的有限准入检查不能硬性限制预分配或元数据字节数。这些是准入和扫描限制，不代表原生存储接口具有分配安全保证。

## 输出与安全边界

解析器假定原生存储状态有效，并使用公共解码投影。原生 `get_messages` 可将畸形的已存储 `tool_calls` JSON 规范化为 `[]`；本解析器不是原始损坏检测器，也不是对抗性数据库审计。即使解码后的工具调用为空，带有 `tool_call_uid` 或 `tool_call_uids` 标记的行仍不合格。可信调用方和存储边界不提供针对恶意进程内 Python 调用方的隔离。

结果不复制原始候选或正文文本。不可变引用是私有临时证据，不是记忆事实、可信指令、保留档案或持久回执。公共诊断仅包含计数和状态；固定的安全失败不披露后端异常、路径、会话标识符或文本。调用方绑定的范围、精确正文及 revision 一致，只建立所支持的来源核对结果。

不提供自动采集许可、来源保留保证、游标推进、记忆写入、压缩提交围栏或持久检查点回执。改写、压缩及后续撤权仍需独立的生命周期和提交契约。不得升级 provider 至 v2，也不得用成功解析满足严格检查点门禁。[43](43-native-checkpoint-boundary-zh.md) 描述的宿主持有持久保证仍未完成。

## 核验边界

单元覆盖及真实固定宿主契约必须区分畸形准备对象、范围/身份/正文失败、扫描及正文上限、精确持久行及用户拆分成功、混合会话的位置屏障及全局身份验证、revision 围栏、读取一致性和仅元数据结果。仅使用合成内容及临时存储。准确执行结果属于受测变更版本；本文不因存在测试就推断测试通过，也不声称生产或模型验收。
