# 105. 自动召回中的字面命名槽位

[English](105-naming-recall-slots.md) | 简体中文

[Issue #151](https://github.com/MosBot-AI/hermes-superagent/issues/151) 为显式启用的[会话召回](49-session-memory-recall-zh.md)和可选[原生提供方](41-native-memory-recall-zh.md)扩展有界[字面槽位识别器](103-automatic-recall-slots-zh.md)。这是本地开发候选，不代表部署、模型验收或完成 #43/#45/#46。

## 范围与行为

完整的单分句中文问题仅含一个所有格标记 `的` 时，可以使用 `叫什么` 或 `叫什么名字` 结尾，其后可跟 `呢` 或 `吗` 及现有句末标点。继续支持现有请求前缀。字面主语和属性都必须存在。姓名和属性保持原样，包括内部功能词字符；混合文字使用现有词边界。验证两个槽位后才省略精确自指 `我`。查询项按输入顺序去重。

内部字面 `叫`、多个所有格、并列标记、多分句和不支持的结尾保留此前解释。这一狭窄语法不删除填充词、不解析别名、不增加同义词、不推断关系，也不理解否定。匹配全部必需项的否定记录仍作为证据保留。旧回退路径仍可能返回无关记录。空结果不能证明某事实不存在。

仅含标记的槽位，例如 `___`、`---` 或分隔的 `- _`，会安全拒绝，包括自指情形；它们不能缩减为更宽泛的单槽位查询。现有限制仍为输入 2,048 个字符、八个不同查询项、每项 128 个字符。已识别的超限计划会拒绝，而不是丢弃后面的项。斜杠命令和含非法控制字符的输入继续被拒绝。

识别出的多项计划要求全部查询项出现在同一返回记录的内容或主题中。过滤在一次新鲜有界读取之后进行，不补查，保留目标和否定事实，排除缺少所需主语或属性的记录。移除项增加 `omitted_records`；`matched_records` 仍描述原始快照。`automatic_filter` 保留全部必需索引和 `refilled: false`。会话信封仍最多包含六条完整记录及 6,000 个 ASCII 转义 JSON 字符。显式搜索/召回、存储结构、激活、撤销、到期、提供方选择和部署边界均不变。修正和遗忘影响新读取，不撤回此前已提供的历史。

重建的开发测试覆盖请求前缀和结尾、字面/混合文字槽位、自指、去重、精确旧回退查询项、限制、非法及纯标记输入、真实后端全部查询项过滤、否定证据、省略元数据和不变的显式检索。生命周期测试覆盖单次读取的新鲜性、缺少主语时弃答及遗忘。原生契约测试通过实际入口点加载的提供方和已注册钩子验证修正、撤销、遗忘、到期、关闭、不变的数据库状态和上下文预算。
