# 当前宿主纯文本 worker 准备

[English](101-current-host-text-worker.md) | 简体中文

## 范围

Issue [#143](https://github.com/MosBot-AI/hermes-superagent/issues/143) 将已有无工具纯文本 worker 提案准备到受支持的 Hermes 提交 `2281116525106e3c109993ccb5dc74d02bfc1427`，不代表采纳或安装修改后的宿主。干净宿主仍没有 `hermes.text-worker.v1` 约定，生产插件仍不会在其上注册规划器。

原始提案针对 `90d6b98fd86d20981ee06ddd5b7d93e4320f26a4`。补丁在当前基线的 `hermes_cli/middleware.py` 和 `hermes_cli/plugins.py` 上无法直接应用。更重要的是，当前配置和执行语义需要重新安全核验。仅成功应用补丁不足以证明移植合格。

候选仍是可信本地、同进程、单请求规划服务。“纯文本”指没有工具或完整子 agent，不是本地推理。单独获授权的请求会把选定任务快照发送给 OpenCode Go `deepseek-v4.1-flash`，正常提供商用量可能产生费用。本准备切片不包含模型请求。

## 当前宿主边界

- `PluginContext` 现位于 `plugins_context.py`。它的生命周期属性必须使用原始插件身份和配置档，不能由旧的一般生命周期属性遮蔽绑定配置档的能力 mixin。
- 中间件保留当前窄签名分派及警告行为。文本路径额外拒绝重复执行下游，包括被中间件吞掉的违规。普通调用者保留原有行为。
- 当前配置可能以 `FailedConfigRead` 返回最后一次可读配置。此映射不是当前同意。能力查询和路由准入必须拒绝它，不能复用旧授权。
- `ConfigBackendUnavailable` 是已知的 `SystemExit` 子类。配置后端故障必须拒绝准入，或在执行已准入时留下真实失败终态。这不会让失败或不明请求变得可重试，也不会吞掉任意进程退出条件。
- managed worker 在导入运行时代码前有意绑定冻结的会话配置。再次调用普通配置读取器不会观察后续撤权。本候选拒绝冻结 worker 上下文，不把快照当作实时权限。
- 隔离的 plugin-host 代理不暴露生产消费者要求的真实只读约定属性，仍不受支持。不得弱化属性检查或修改用户的隔离设置，让实验看似可用。

准确路由、配置档绑定、独立同意、有界不可变载荷、不重定向/不读取环境的传输、单次尝试约束和持久本地领取仍是必要条件。服务不继承工具、父历史、MCP、递归委派、工作区或辅助模型工作。返回草稿是不可信数据，不是任务完成证据。

未修改的原生分派器可能在进入消费者前读取配置，例如确定 pre-tool hook 超时时。此处的配置后端故障可能在候选处理前中止分派。本切片不声称所有宿主入口都返回归一化错误，也不添加全局 `SystemExit` 捕获。此前置故障不会准入 worker 请求。

## 为何候选通过不等于 Gateway 采纳

普通 Gateway 执行可能使用 managed worker。拒绝冻结配置是有意的安全边界，不是已经完成集成。若要在该模式下提供支持，需要宿主拥有的当前授权路径，以及明确的准入/撤权顺序和进程绑定执行身份。重读同一 worker 快照、绕过宿主配置策略读取，或改用不受约束的一般委派，都不是这份约定。

一般生命周期不能作为回退：空工具集可能意味着继承，MCP 和委派工具可能重新加入，子代理初始化也可能继承历史相关及记忆行为。项目在 `tests/contracts/test_worker_routing_contracts.py` 中保留可执行反例。

## 采纳选项及里程碑依赖

两种部署选择都需要明确审阅的宿主版本和真实准确路由验收：

1. **上游采纳。** 准备当前基线实现和安全论证，在向 NousResearch 提交前获得授权。上游审阅可帮助确定公共 API 并减少长期分歧，但接受及发版时间是外部依赖。在本仓库准备不等于已经提交上游。
2. **维护宿主发行版。** 明确选择 fork 或补丁系列的维护者、版本/发布身份、安全更新、兼容性迁移、打包、回滚和支持责任。此路径提供交付控制权，也带来持续宿主维护责任。可丢弃的打补丁副本不是发行版，本 Issue 不替用户作出此选择。

任一选择仍需完成目标部署适用的 managed-worker/隔离插件约定、受支持安装和同意，以及真实提供商证据。宿主标记仅声明可信代码兼容性，不是防御同进程恶意代码的沙箱。

本切片是 E3.3 的直接前置工作。完整 E3.3/E3.5 仍需持久执行身份、提供商侧不明结果核对、预算/并发策略和真实取消语义。文本规划不提供一般带工具 worker。E9 有界路由依赖自身的可信上下文与预算门槛，不会因本移植而就绪。

E4 提醒另需原生创建/核对及送达所有权。E2.8 checkpoint/来源提案具有不同的原生事务和保留约定，两者都不会因采纳 worker API 自动满足。已有显式本地任务、交接和记忆流程继续使用未修改的干净基线。

## 证据及保留限制

[工件清单](../experiments/text-worker/manifest.json)和[运行器](../experiments/text-worker/run_tests.py)将当前补丁、源码及所选离线测试绑定到准确宿主。旧基线测试数量、此前的 `ConnectError` 提供商尝试及仓库安装扫描拒绝仍是历史证据，不是本候选的结果。后续干净宿主生产包 Gateway 验收，包括 [#142](https://github.com/MosBot-AI/hermes-superagent/pull/142)，没有安装本 worker 提案。

所选宿主/消费者及冷启动包测试不是完整上游套件、真实 Gateway worker 验收或真实提供商验收。HTTP 测试传输使用合成数据，不需要个人配置档、凭据、提供商请求或重试此前被拒绝的 socket 操作。完成前，独立审查和准确源码 CI 证据会链接到 #143 及其 PR。

账本仍最多保留 64 条记录，不淘汰终止记录，也不恢复未观察到的提供商结果。任何诊断、重启或新 key 都不授权重试结果不明的请求。缺少单调权限修订的配置 ABA、准入后的变化、既有对话披露及提供商计费仍是明确限制。
