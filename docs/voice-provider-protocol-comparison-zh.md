# E0.8 在线语音协议对照

[English](voice-provider-protocol-comparison.md) | 简体中文

官方文档于 2026-11-12 核对。本对照涵盖 GPT-Live、OpenAI Realtime 语音到语音模式和 Gemini Developer API Live 接口，记录文档所述的传输行为及其对 E0.8 的影响。Hermes 测试夹具的实际覆盖见[当前固定版本兼容性清单](voice-compatibility-inventory-zh.md)。

## GPT-Live

- **连接与媒体。** 应用服务端使用项目 API 密钥，通过 `POST /v1/live/sessions` 提交 JSON 会话配置和客户端 SDP offer。客户端应用返回的 `transport.sdp`，等待 `session.started`。WebRTC 协商媒体格式，并在数据通道上传输应用事件。服务商还提供独立的服务端 WebSocket `/v1/live/sessions`，使用 `session.start` 和 `session.input_audio.append`。WebSocket 的输入和输出使用同一固定格式，默认为 24 kHz 单声道有符号小端 PCM16，也可使用 16 kHz PCM16 或 8 kHz G.711 μ-law/A-law。固定版本 Hermes 实现了配置客户端委派的 SDP 交换。 [WebRTC 指南](https://developers.openai.com/api/docs/guides/voice-webrtc?api=live) · [创建会话](https://developers.openai.com/api/reference/resources/live/methods/create) · [WebSocket 指南](https://developers.openai.com/api/docs/guides/voice-websockets?api=live)
- **语音、打断与委派。** 应用持续发送输入音频。GPT-Live 处理重叠的输入和输出，并决定何时发言或委派。应用将 `session.delegation.created` 与自己的上下文和任务状态关联，再按委派 ID 发送更新。输入静音作用于服务商输入。播放器或媒体中继需另行停止或清空输出。审核输出语音需由应用完成分段或 VAD，被拦下的语音仍可能留在服务商上下文中。所核对的控制接口支持本地播放控制和纠正指令，未说明按实际播放偏移截断上下文的操作。客户端委派任务由应用负责完成或取消。 [回合控制权](https://developers.openai.com/api/docs/guides/live-migration) · [会话指南](https://developers.openai.com/api/docs/guides/live-conversations) · [客户端委派](https://developers.openai.com/api/docs/guides/live-delegation?delegation-mode=client) · [播放控制](https://developers.openai.com/api/docs/guides/voice-server-controls?api=live)
- **恢复与结束。** `session.closed` 提供结束原因和最终用量，达到会话时长上限时原因为 `expired`。连接在收到该事件前中断时，最终用量无法确认。文档所述的分叉要求源会话已在项目授权下完成录制与保存，分叉使用新连接和新会话 ID，录制保留 30 天。无法分叉时，使用经许可的文本历史开启新会话。旁路连接可重新附加到仍在运行的主会话，仅重放此前三秒的事件。事件原有的 `event_id` 会随重放保留。此重放无法确认播放或外部效果。重试前需核对后端未决工作。所核对的分叉流程未保证可重放状态不明的媒体或外部效果。 [会话指南](https://developers.openai.com/api/docs/guides/live-conversations) · [旁路连接附加](https://developers.openai.com/api/docs/guides/voice-server-controls?api=live)
- **用量与数据。** `session.usage.updated` 和 `session.closed` 报告累计语音秒数。后端模型和工具用量另行计量。创建 WebRTC 会话会计入初始化时间，启动后抵扣。已完成录制的可选存储默认关闭。OpenAI 列出的默认滥用监控保留期为 30 天，符合条件时可使用零数据保留（ZDR）。启用 ZDR 后 `store` 被强制关闭，录制下载和分叉不可用。委派后端的保留规则需另行核对。 [用量与费用](https://developers.openai.com/api/docs/guides/voice-latency-cost?api=live) · [OpenAI 数据控制](https://developers.openai.com/api/docs/guides/your-data)

## OpenAI Realtime 语音到语音

- **连接与媒体。** WebRTC 使用 `/v1/realtime/calls`。统一连接流程通过应用服务端提交 SDP 和会话配置，也可使用通过 `/v1/realtime/client_secrets` 签发的短期密钥。音频通过协商后的媒体轨道传输，事件通过数据通道传输。服务端 WebSocket 使用 `/v1/realtime`，通过事件传输 base64 音频。WebSocket PCM 使用 24 kHz 单声道有符号小端 PCM16。会话 schema 也列出 G.711 μ-law/A-law。 [WebRTC 指南](https://developers.openai.com/api/docs/guides/voice-webrtc?voice-api=realtime) · [WebSocket 指南](https://developers.openai.com/api/docs/guides/voice-websockets?voice-api=realtime) · [客户端密钥与会话 schema](https://developers.openai.com/api/reference/resources/realtime/subresources/client_secrets/methods/create)
- **VAD 与打断。** 支持此功能的语音到语音模型默认使用 `server_vad`，也可使用 `semantic_vad` 或由客户端划定边界。关闭 VAD 后，客户端提交音频缓冲，并显式为手动回合请求响应。启用自动打断时，VAD 可取消当前响应。WebRTC 由服务端管理输出缓冲和截断。WebSocket 客户端停止本地播放，并用 `conversation.item.truncate` 的 `audio_end_ms` 传入已播放时长。手动打断时，对进行中的响应发送 `response.cancel`，再用 `output_audio_buffer.clear` 清空 WebRTC 输出，或执行 WebSocket 的本地停止和截断。以状态为 `cancelled` 的 `response.done` 确认响应取消。服务商缓冲统计和设备实际播放需要各自的证据。 [VAD 指南](https://developers.openai.com/api/docs/guides/realtime-vad) · [音频与打断流程](https://developers.openai.com/api/docs/guides/realtime-conversations)
- **恢复与过期。** 客户端密钥过期限制新建会话，已启动的会话可以继续。密钥有效期内可创建多个会话。文档注明默认有效期为 600 秒，可配置为 10 至 7,200 秒。语音到语音指南列出的会话时长上限为 60 分钟。所核对的客户端连接流程未提供断线后重放状态不明的音频或恢复完整对话的恢复 handle。无法恢复原会话时，创建新会话，仅恢复经授权且已确认的上下文，并明确提示中断。 [客户端密钥参考](https://developers.openai.com/api/reference/resources/realtime/subresources/client_secrets/methods/create) · [Realtime 对话](https://developers.openai.com/api/docs/guides/realtime-conversations)
- **用量与数据。** `response.done` 包含响应状态，也可携带按模态细分的 token 用量。`rate_limits.updated` 报告限额状态。持续实时转写和翻译按各自规定使用独立的时长计费。OpenAI 数据表列出 `/v1/realtime` 的应用状态保留为无，默认滥用监控保留期为 30 天，符合条件时可使用 ZDR。 [服务端事件](https://developers.openai.com/api/reference/resources/realtime/server-events) · [用量与费用](https://developers.openai.com/api/docs/guides/voice-latency-cost?voice-api=realtime) · [OpenAI 数据控制](https://developers.openai.com/api/docs/guides/your-data)

## Gemini Developer API Live

- **连接与媒体。** `v1beta` 是有状态的 WebSocket 接口，API 参考将其标为预览。`gemini-3.8-live` 模型的正式发布属于独立的发布状态。先发送 `setup`，再等待 `setupComplete`。受信后端可为客户端签发用于受限 WebSocket 入口的短期令牌。服务端连接可使用 API 密钥。音频使用裸有符号小端 PCM16，原生输入为 16 kHz，可按 MIME 声明的输入采样率重采样，输出为 24 kHz。 [传输参考](https://aistudio.google.com/api-reference/live/bidi-generate-content) · [音频格式](https://aistudio.google.com/docs/live-api/capabilities#audio-formats) · [模型变更记录](https://aistudio.google.com/docs/changelog#09-15-2026) · [短期令牌](https://aistudio.google.com/docs/live-api/ephemeral-tokens#create-a-token)
- **VAD 与打断。** 默认开启自动活动检测。客户端可关闭它并发送 `activityStart` 和 `activityEnd`。收到 `serverContent.interrupted` 后，停止并清空本地播放。Google 所描述的历史包含服务端已发送的内容。所核对的公开 schema 提及可选播放状态，但未说明等价的精确播放偏移截断操作。`toolCallCancellation` 标识应取消的工具调用。实际外部效果需独立跟踪。 [活动检测与打断](https://aistudio.google.com/docs/live-api/capabilities#interruptions) · [服务端内容](https://aistudio.google.com/api-reference/live#BidiGenerateContentServerContent) · [工具取消](https://aistudio.google.com/api-reference/live#BidiGenerateContentToolCallCancellation)
- **恢复与过期。** `GoAway` 提示连接即将更替。选择启用恢复后，使用最近适用且 `resumable: true` 的 handle。文档注明会话终止后该 handle 有效两小时。handle 可能早于不可恢复的生成或工具工作，无法证明交付或精确重放。指南列出的连接时长约为十分钟。关闭上下文压缩时，纯音频会话上限为 15 分钟，音视频会话上限为两分钟。短期凭证默认允许在一分钟内新建会话，并在 30 分钟内发送消息。有效期内恢复会话可复用令牌，无需再消耗一次使用次数。 [会话管理](https://aistudio.google.com/docs/live-api/session-management) · [恢复更新 schema](https://aistudio.google.com/api-reference/live#SessionResumptionUpdate) · [令牌有效期和次数](https://aistudio.google.com/docs/live-api/ephemeral-tokens#create-a-token)
- **用量与数据。** `usageMetadata` 报告按模态细分的 token 数。限额随模型、项目和用量等级变化。所核对的资料未给出固定的 Live 配额或完整的 WebSocket 关闭码重试映射。生成恢复 handle 时，包含音频、视频和文本的对话状态可保留最多 24 小时。关闭恢复可避免这项特定存储。付费服务另有有限的滥用监控日志，非付费服务适用不同的数据使用条件。需要核对适用的账号、地区和服务条款。 [用量](https://aistudio.google.com/api-reference/live#UsageMetadata) · [限额](https://aistudio.google.com/docs/rate-limits#current-rate-limits) · [数据保留](https://aistudio.google.com/docs/zdr#customer-data-retention-and-achieving-zero-data-retention) · [服务条款](https://aistudio.google.com/docs/terms)

## 兼容性边界

各适配器使用独立的协议 ID、事件、凭证作用域、停止语义和恢复策略。文件 ASR/TTS 兼容性无法证明这些实时传输中的任何一个可用。服务商凭证用于访问服务商的服务。Hermes 所有者身份、定向取消、实际播放和原生外部效果确认均需各自的证据。

这些资料记录核对当日的服务商契约。原生 GPT-Live 夹具使用合成上游验证请求构造和拒绝路径。实际传输、账号限额、价格、保留设置、音质和设备行为均跳过。项目尚未选定生产用 Realtime 或 Gemini Live 适配器。
