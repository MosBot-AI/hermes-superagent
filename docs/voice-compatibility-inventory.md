## Scope and reproducibility

[Issue #36](https://github.com/MosBot-AI/hermes-superagent/issues/36) verifies the native voice contracts available for reuse. The tested host is clean Hermes `2281116525106e3c109993ccb5dc74d02bfc1427`, recorded in [compatibility.json](../compatibility.json). The baseline at project commit `ba614693e2a6b6ec4ad8bcbd4f395ac586021a27` passed 4,843 unit tests and 1,542 native contracts across 88 files on Linux with Python 3.14.9 and the prepared Hermes `dev` and `test` environment. The [development checks](../README.md#development-checks) verify the clean host revision and record the environment fingerprints. The [merged-main CI run](https://github.com/MosBot-AI/hermes-superagent/actions/runs/43246720356) also passed, and the [Issue evidence](https://github.com/MosBot-AI/hermes-superagent/issues/36#issuecomment-6827997518) records verification of the matching offline package.

The tests use temporary profiles, generated PCM and text, fabricated credential markers, fake devices, in-memory ASGI messages and fenced turn scheduling. The SDP exchange replaces vendor I/O. The admission harness permits an IPv6 loopback availability probe without listening or connecting.

The simulator has its own `personal.voice.simulation-config.v1`, `personal.voice.simulation-frame.v1`, `personal.voice.simulation-capabilities.v1` and `personal.voice.self-test.v1` revisions. Native audio WebSocket tests negotiate `hermes-gateway-v1`. Canonical `prompt.submit` and `prompt.receipt` are in [Hermes gateway OpenRPC version 1](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/apps/shared/src/gateway-contract.openrpc.json). The exact host SHA identifies the Python and native HTTP contracts in this inventory. The [dated provider protocol comparison](voice-provider-protocol-comparison.md) records the external protocol revisions and documentation evidence separately.

## Readiness by mode

`Installed` identifies the package, provider fixture or native code present in the test environment. `Configured` identifies an exercised selection or policy. `Credential-resolvable` applies to the named credential path and test scope. `Health-checked` records the check actually performed. `Certified for mode` requires acceptance for that operating mode. A catalog readiness flag, a streaming capability flag and resolution of a GPT-Live key are different observations.

## Reusable contracts and missing seams

- The public extension points are `ctx.register_transcription_provider` and `ctx.register_tts_provider`. The ASR contract covers file transcription and optional one-utterance streams. A single feeder supplies 16 kHz mono s16le to `push_audio`, and `finalize` returns the normal result envelope without raising. The base stream contract has no cancel method. TTS `synthesize` writes a file and raises on failure. PCM streaming is opt-in at a declared rate and must be thread-safe for concurrent sentences. `warm` and `release` are best-effort lifecycle methods. [Registrars](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/hermes_cli/plugins_context.py#L865-L872) · [ASR ABC](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/agent/transcription_provider.py) · [TTS ABC](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/agent/tts_provider.py)
- Native audio routes and canonical gateway RPC are existing client contracts with their own admission and framing. The native `pre_transcription` hook can adjust file transcription context. The streaming wrappers, internal TTS `register` decorator, recorder, sidecar stop helpers and authority implementation are host internals. The pin exposes no public interchangeable VAD or generic voice-session registrar. Hosted plugin streams need a supported cross-process media seam. The [review-only IPC experiment](21-native-voice-ipc-experiment.md) targets a historical pin. The native ASGI fixtures exercise built-in routes. Project plugin WebSocket or SSE forwarding through the isolated dashboard remains unverified and disabled. [Native audio routes](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/hermes_cli/web_routers/audio.py) · [Internal TTS streaming](https://github.com/NousResearch/hermes-agent/blob/2281116525106e3c109993ccb5dc74d02bfc1427/tools/tts_streaming.py) · [Client transport constraints](14-client-api-contracts.md)
- A hosted-auth boolean, model key or source title supplies no verified owner identity. The project keeps live voice disabled pending applicable trusted owner/session, credential and recipient approval, budget, media transport, playback and scoped cancellation evidence. Native turn cancellation and external-effect cancellation require separate controls and receipts. Health checks may not initiate paid calls or send sample audio without authorization. Release gates apply to the affected mode, including E0.6 for an optional project HTTP/control surface and E0.4/E0.7/E1 where authorization or effects require them.
