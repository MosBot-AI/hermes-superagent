# 94. 仅供审阅的回执绑定原始来源读取

[English](94-receipt-source-reads.md) | 简体中文

## 状态与价值

[Issue #129](https://github.com/MosBot-AI/hermes-superagent/issues/129) 在已合并的 [PR #128](https://github.com/MosBot-AI/hermes-superagent/pull/128) 基础上扩展[宿主回执提案](92-native-checkpoint-sources-zh.md)及[消费者恢复日志](93-source-receipt-recovery-zh.md)。历史记账无法提供未来来源绑定消费者需要的原始文本。分别读取回执状态和来源文本，可能跨越删除或更正而拼接出不一致的观察。

隔离提案新增 `read_receipt_sources(db, session_id, attempt_id, expected_receipt_id)`。它在同一个原生 SQLite 读取快照内读取回执有效性、精确成员关系和原始来源行。显式测试消费者打开只读原生存储后调用此操作，既不消费恢复日志，也不保存返回文本。

本实现仅供审阅，尚未提交上游且未激活。它不是交付中的记忆 provider 或自动采集路径。Hermes 仍固定为 `2281116525106e3c109993ccb5dc74d02bfc1427`，交付 provider 保持 API v1，父项 #43/#45 仍然开放。未启用规范记忆接受、游标推进、provider-v2 检查点、后台读取器、REST 接口、模型调用、安装或发布。

## 绑定与结果

可信调用方提供精确 `SessionDB`、当前会话、attempt 及预期回执哈希。请求不能选择文件路径、SQL 或来源行。格式正确但与绑定回执不匹配的预期哈希会触发固定的 `receipt_mismatch` 错误，不返回来源文本。无效调用参数触发固定安全请求错误。标识符和哈希属于私有元数据，不代表人类身份验证、授权，也不是可匿名公开的信息。

- `available_at_snapshot`：`available` 为 true，附精确回执 ID 和完整 `sources` 列表。每条来源包含 `row_id`、`role`、`content`、`message_uid` 和 `absorbed_message_uids`，按原生行 ID 排序。内容为解码后的原始纯文本。独立原生行仍分别返回，包括准备阶段被合并用户候选所代表的多行。不会将生成的压缩摘要重建为原始证据。
- `absent`：该快照不存在匹配回执。不返回来源载荷，也不创建缺失的回执 schema。
- `invalidated_or_unknown`：无法确认回执/来源有效性，包括常规来源修改或删除。不返回部分来源载荷。
- `unavailable`：存储、schema、解码或有界输出校验失败。结果不含来源载荷或原始后端异常文本。

每种结果都报告 `durable_memory_checkpoint: false`。可用性是一项观察，不是规范写入、记忆游标、交付回执或持续授权。调用方仍须单独确认读取、保留、使用或传输来源材料的权限。来源文本始终是不可信证据，不是指令，也不证明作者身份或事实真实性。

## 上限与删除边界

成功读取最多接纳 256 条原始行、合计 1,024 个消息标识、每行 16,384 个解码内容字符和合计 65,536 个内容字符。序列化 lineage 最多 36,866 个字符。原始行中字符串字符数与字节值长度之和，限制为每行 262,144、合计 2,097,152。规范 ASCII 编码 JSON 结果最多 1,500,000 字节。所有行必须整体通过，不能部分返回。这些是读取后的准入/输出限制，不保证原生 SQLite 驱动从不分配更大的输入。

既有持久化更新/删除触发器继续使回执失效。在下次读取快照建立前已经提交的修改会阻止新的来源返回。在 WAL 模式下，读者持有较早快照时提交的删除，可以与完整历史结果并存。下一次读取会看到失效。操作不会拼接删除前的状态与删除后的行，也不会恢复已删除载荷。结果返回之后的删除，无法撤回调用方、模型上下文、日志、导出或备份中已经持有的副本。这既不是安全擦除，也不在来源读取和后续记忆写入之间提供栅栏。

可信原生存储的假设不变：原始 schema 篡改、恶意进程内代码、手工替换、克隆和备份回滚不属于此契约。绑定回执不是 capability token。回执及日志元数据不是第二份转录归档；此操作不新增持久载荷存储。

## 验证与后续门禁

使用[实验产物复现说明](../experiments/native-checkpoint-sources/README-zh.md#安全复现)。manifest 绑定已暂存宿主补丁、读取消费者及新增来源读取测试文件。隔离 CI job 在单独应用补丁的临时宿主上执行提案测试，再执行选定原生回归。生产运行包继续排除此实验。

测试使用真实临时原生 SQLite 存储与合成文本。覆盖精确回执/会话绑定、重启、原生行顺序与合并用户输入、缺失来源、读取前及读取中的修改/删除、有界输出、损坏存储和不创建 schema 的行为。实际执行计数记录在 manifest 与 PR 证据中；存在测试不等于测试已通过。完整上游、真实模型及生产 provider 验收独立，均不声称完成。

后续记忆消费者仍需显式保留/接受授权、跨发布的删除抑制、持久记忆结果及游标推进。来源读取与独立提交的记忆写入不是跨存储原子事务。本切片有意不关闭这些门禁。
