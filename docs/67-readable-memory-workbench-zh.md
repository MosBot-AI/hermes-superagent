# 可读的原生记忆工作台

[English](67-readable-memory-workbench.md) | 简体中文

## 人类可读输出与稳定结构化输出

原生 `/personal-memory` 命令的 help、list、search、search-terms、recall、show 和普通 remember/correct/forget 回执现在默认显示可读文本。中文保持可读，每项结果显示相关 ID/revision 和状态；完整记录文本得到保留，字段带引号，换行、控制字符及双向/格式控制符被转义。存储的文字不能伪装成额外生成的状态行或命令。它仍是不可信数据，不是授权或经验证的原始作者身份。

```text
/personal-memory list
/personal-memory search-terms project deadline
/personal-memory show RECORD_ID
/personal-memory --json list
```

**输出格式兼容性变更：**解析原生命令输出的脚本必须在操作之前显式添加 `--json`。它保留原 `personal.local-memory.v1` envelope，包括准入/配置/卸载及非法命令错误。`--json` 只改变呈现，不改变访问、校验、存储或重试。错误位置或重复的选项不被当成新命令接受。已有模型读写工具继续返回 JSON，schema 不变。内部 `LocalMemoryCommands` 调用者保留 JSON 构造默认值，只有原生插件注册选择文本。

候选审核/接受、导出、变更记录和 checkpoint 有意保留完整结构化输出。不会为了简化涉及安全的审核而删掉来源引文、保留期限选择或 checkpoint 字段。未知的未来结果结构也回退到原 envelope，不把已经完成的操作变成错误。渲染从不重新打开存储、读取下一页、重试写入或发送外部消息。

## 视图含义

- 列表/搜索/多词搜索显示返回的完整记录、状态、主题和过期时间。被遗忘记录已清除权威载荷，但不代表擦除先前历史、导出或备份。已过期记录仍在存储中，只是排除在普通新召回之外。
- 详情还显示创建/更新时间及最后修改路径/会话引用。这些是已记录元数据，不是经验证的人类意图。
- 分页在带引号的下一页命令中保留当前查询/词、条数和显式过期检查选项。这只是建议的**读取**，不是执行。分页实时读取，页间可能发生变化；没有匹配不能证明事实不存在。
- 召回显示后端省略记录数和 ASCII JSON 字符预算。这不是 token 预算，也不保证检索出所有相关事实。
- 新修改回执显示已保存的 ID、revision、request ID 和事件序号，不重复存储正文。精确重试标明它是先前已记录的结果，不是当前状态。重放回执不能逆转遗忘。
- 错误保留精确错误码和可重试标记。结果未知的写入不会被说成成功，或“失败所以没有效果”；应查看当前状态，或使用相同 request ID 和完全相同的参数重试。格式化失败仍保留真实回执。

没有增加新操作、记忆 schema、权限、自动召回、生成投影文件、provider 选择或部署。此工作台不是 E2.7 单独规划的持久 Markdown 投影。

## 验证

单测与固定 Hermes 原生命令测试覆盖文本/JSON 输出、非 ASCII/控制文本、分页命令重用、过期/遗忘状态、修改回执和旧结果重放、结构化回退、非法输入、存储错误、关闭配置、不支持来源及卸载后保留回调。存储/后端和模型工具契约保持不变。合成 profile 和离线夹具不是实际用户或生产验收。
