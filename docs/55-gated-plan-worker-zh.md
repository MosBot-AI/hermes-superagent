# 受门控的任务规划 worker 集成

[English](55-gated-plan-worker.md) | 简体中文

## 包级集成，不等于部署验收

本次把经过审阅的纯文本任务消费者、持久账本及展示移入生产包，并连接真实插件入口，不代表安装插件或上游采纳宿主补丁。正式干净宿主基线 `2281116525106e3c109993ccb5dc74d02bfc1427` 缺少所需 API/权限，必须不注册规划 worker。

`plan_worker` 默认 false。注册要求准确宿主约定 `text_worker_contract == 'hermes.text-worker.v1'`、当前标准 `llm.text_worker` 同意，以及本地任务/会话/模型工具前提。仅有同名方法不够。不支持或未同意的宿主不会回退到通用 subagent launch、`ctx.llm`、其他提供商或其他模型。

worker 工具集为 `personal_agent_plan_worker`，同时要求所需生命周期方法存在。注册时不支持或未同意不会阻止普通插件功能，状态会报告原因。若注册已跳过，启用配置或授予同意后需要重新加载插件。每次 worker 操作重新检查当前约定标记和同意。`plan_worker` 要求 `local_model_tools=true`，后者要求本地任务及本地会话。

## 明确单任务授权

原生 `/personal-plan-worker` 提供 `allow TASK_UUID REVISION REQUEST_ID`、`revoke REQUEST_ID`，以及已存请求工作台 `list`、`status KEY`、`draft KEY`、`stop KEY`。原生命令不启动工作。`personal_task_plan_preview` 工具使用请求 ID 通过 `launch`/`result` 消费明确授权或读取结果，不能自行产生授权、扩大任务范围或执行计划。

授权在 120 秒后过期。唯一提供商/模型为 OpenCode Go `deepseek-v4.1-flash`，需批准准确端点，最多 1024 输出 token，单请求超时 30 秒。授权披露选定任务数据将被发送，可能产生正常模型用量。上下文白名单为任务 ID、修订、标题、状态、项目、到期日、工作状态及有界详情，不隐式添加依赖或原生进度元数据。worker 没有工具或外部任务动作，响应只是待审阅的不可信规划草稿，不代表任务完成。

## 保留的边界

宿主请求之前先持久提交本地领取。结果不明或未观察到结果时，不自动重试，也不在重启后通过新授权恢复。不得用新键重试不确定请求。撤销或停止未启动请求可阻止启动；此消费者不提供执行中取消，也不能退回用量费用。

私有账本保存标识、哈希及观察到的终态草稿，不保存任务快照正文。最多 64 条，不自动清理或淘汰；终态回执必须不超过 32000 个 ASCII 序列化字符。容量需要可信人工审阅，不应删除账本来允许重复提交。已返回的对话内容不能撤回。模型工具读取结果保留准确批准路由门控；明确的原生已存草稿视图送往客户端，客户端可能显示或缓存，不自动提交给模型。

宿主 profile 绑定、同意撤销、专用不重定向传输、不从环境派生路由、固定安全诊断及单次尝试行为，仍属于[已审阅宿主提案](48-task-worker-proposal-zh.md)。约定标记是可信宿主兼容声明，不是对抗恶意已安装宿主代码的沙箱。

## 证据与剩余门槛

集成仅以隔离补丁宿主及离线 MockTransport 夹具验证，不增加真实模型、网络、安装或 Gateway 验收声明。此前获授权的合成提供商尝试以 `ConnectError` 结束，没有 HTTP 状态或模型响应，也未重试。此前官方安装被未修改的扫描器阻止；包级接线不授权覆盖或绕过。

宿主采纳、获授权安装、真实提供商执行及完整运行验收仍未完成。通用 worker 编排、提供商侧不明结果核对、预算/并发策略及带工具 worker 也未完成。参见[路线图](08-roadmap-and-acceptance-zh.md)与[实验证据](../experiments/text-worker/README-zh.md)。
