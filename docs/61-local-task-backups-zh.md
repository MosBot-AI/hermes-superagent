# 显式本地任务备份

[English](61-local-task-backups.md) | 简体中文

## 状态与范围

这是 #17（E2.1/E8.3）已实现的开发切片，不代表完整备份/恢复或 M1 验收。本地操作员可以创建和检查当前配置分区 `tasks.sqlite3` 的一致独立快照。内容包括任务文本、历史回执、修订号、依赖边和保存的原生观察记录；不包括记忆、登记/授权、凭据、宿主会话、原生 Kanban 状态及其他数据库。这不是整个配置分区的备份、加密保险箱、跨分区迁移，也不授权重放外部操作。

只有原生本地 CLI 暴露此操作。没有对话命令、模型工具、调度器、网络传输、自动备份或自动恢复。必须已显式选择现有 `mode: local_tasks`，每次命令都重新检查模式和绑定分区。不选择新配置或提供方。

## 使用方式

```bash
hermes personal-agent task-backup create --name before-upgrade
hermes personal-agent task-backup inspect --name before-upgrade
```

名称为 1–64 个 ASCII 字母、数字、下划线或连字符，以字母或数字开头。不接受任意目标路径或覆盖选项。文件存放在当前分区的 `plugin-data/hermes-personal-agent/task-backups/NAME.sqlite3`。目录为私有（0700），快照为私有普通文件（0600、单硬链接）。拒绝已存在的不安全文件或目录，绝不自动修复。不输出私有路径或任务正文。

两个命令都返回 `personal.task-backup.v1` JSON，包括名称、任务数据库版本、结构/完整性结果、任务/回执/事件/依赖数量、字节数及 SHA256。快照未变化时，成功的 `inspect` 返回相同元数据。摘要可与另行保存的回执比较以检测字节变化，但不能证明所提供数据库的真实性或可信性。`automatic_restore: false` 明确区分快照与可恢复的整分区导出。

## 一致性与失败行为

创建时只读打开已有任务数据库并开始读事务。在不初始化、迁移或 checkpoint 源库的情况下，检查精确的当前结构并执行 SQLite 完整性及外键检查。SQLite 备份 API 将同一快照（含已提交 WAL 内容）复制到私有临时文件，输出转为 DELETE 日志模式，关闭、检查、计算摘要并同步，再以不覆盖方式原子发布。返回成功前同步目录。

源快照建立后提交的写入不会部分混入备份。备份是时间点视图，不保证是命令返回时的最新状态。长读事务可能延迟回滚日志模式下的写入，因此备份不宜频繁。支持最多 512 MiB 逻辑数据库页/输出，处理预算为 30 秒并有有界 SQLite 锁等待。这不保证实时截止，也不保证任意文件系统的断电持久性。

名称已存在时返回 `backup_exists`，绝不覆盖。存储不存在时返回 `backup_not_found`，不会创建任务库。外来、修改或非当前结构均拒绝处理。检查快照时拒绝任何 journal/WAL/SHM 旁文件。发布前超时或验证失败不会留下已命名备份；正常清理会删除临时文件。进程被终止可能留下私有 `.pending-*` 文件，它不是完成的备份，也不会被自动接纳。发布后目录同步或结果传递失败时，应先检查同名快照再决定重试；不能假设失败代表文件不存在。不自动重试或清理用户快照。若进程在链接发布后、临时名称删除前退出，已命名快照和 `.pending-*` 别名可能指向同一 inode。检查会有意返回 `unsafe_storage_file`，直到操作员核实匹配 inode/所有权，并离线仅删除该临时别名。不要删除未经核实的链接或绕过硬链接检查；核实源库后也可以使用新备份名称。

文件系统检查覆盖预先存在的符号链接、硬链接、非私有文件和可被其他用户写入的目录；不能隔离恶意同 UID 或同进程代码的文件竞争。快照是明文，即使实时任务已修改，也可能保留历史文本。保留期限和后续共享由用户控制；禁用/卸载不会删除快照。

## 恢复边界与验证

没有命令替换实时存储或导入旧快照。恢复旧任务状态可能复活终态任务、旧修订或原生引用；完整恢复需要独立的先停止再启动且理解授权的流程。不要把备份覆盖到运行中的分区，也不要借此触发旧外部工作。目前它是供主动离线检查的已验证恢复材料，不是自动恢复功能。

合成测试覆盖 DELETE/WAL 快照、并发提交、隔离测试副本中的完整数据与回执重放、安全发布、重复名称、不安全文件、不修改源库的结构拒绝、损坏/旁文件、大小/时间限制、发布后同步失败及 CLI 错误脱敏。固定宿主测试覆盖原生注册、创建、重载/检查和实时模式撤销。本切片不使用个人数据、真实模型、Gateway、提供方调用或 MacBook。准确数量和 CI 对应最终提交，#17/E8 的更广泛验收仍开放。
