# 36. 有界显式记忆召回

[English](36-bounded-memory-recall.md) | 简体中文

后续：[45](45-explicit-memory-expiry-zh.md)按一次捕获的 UTC evaluated_at，在排序/预算计算前排除已到期的 active 记录。召回没有包含已到期记录的覆盖选项。返回行含 expires_at/expired；先前返回的包在到期后仍可能留在宿主/模型上下文中。

状态：已在现有本地记录库上实现，提供显式原生命令和独立激活的模型读取操作。这是推进 [30](30-pluggable-memory-contracts-zh.md) 的一项实用检索能力，不是自动提示注入、语义搜索、绑定来源的提取或原生 MemoryProvider 桥接。现有 provider 和 profile 设置保持不变。

## 1. 命令与激活

启用现有[本地记忆选项](31-explicit-local-memory-zh.md)后，可使用：

```text
/personal-memory recall "早餐" "燕麦奶" --limit 6 --max-chars 6000
```

分别配置[记忆模型工具](32-session-scoped-memory-tools-zh.md)，并在会话中执行 `/personal-memory-tools enable-read` 或 `enable-write` 后，当前配置的模型可请求：

```json
{"action":"recall","queries":["早餐","燕麦奶"],"limit":6,"max_chars":6000}
```

此操作属于 `personal_memory_read`。任务工具激活不会授予记忆权限。未激活、过期、会话/路由/profile 不匹配、缺少正在执行的原生 turn、重载、卸载和配置禁用，继续遵循现有拒绝逻辑。没有新增权限、后台回调、模型调用、定时任务或 provider 选择。直接命令沿用其他记忆命令的可信单用户原生 LOCAL 准入。

## 2. 确定性检索与限制

`queries` 接受 1–8 个不重复、非空白的字面字符串，每个最多 128 个字符。它们与当前内容或主题进行区分大小写的子串匹配。中文和短关键词无需分词器即可使用；SQL 通配符和引号都按字面处理。不进行词干处理、翻译、语义相似度、推断式查询扩展或外部嵌入调用。应选择有效关键词，不要把整句自然语言问题当成语义搜索。

先按命中的不同关键词数量排序，再按主题命中数量，最后按记录创建序号倒序排列。纠正旧记录不会使其变成新创建的记录。即使命中多个关键词，同一记录也只出现一次。`matched_queries` 表示提交的查询列表中从零开始的位置，不是置信度。`limit` 默认为 6，允许 1–20。

`max_chars` 默认为 6,000，允许 1,024–12,000。它限制返回的 `items` 数组的精确 ASCII JSON 序列化长度，包括元数据、转义 Unicode、引号和分隔符，即 `json.dumps(items, ensure_ascii=True, sort_keys=True)`。`items_json_chars` 返回该长度。这不是 tokenizer 预算，不含少量响应元数据和原生工具/命令外层封装。中文字符按转义后的 JSON 空间计费，因此相较 ASCII 文本可能只能容纳更少记录。

结果只返回完整记录，不截断或总结存储的文字。过大记录会被跳过，排序较低但更短的匹配仍可能进入结果。`matched_records` 统计全部匹配的活动记录。`omitted_records` 统计因条数或大小限制而未返回的匹配。`skipped_for_budget` 只统计达到条数上限前实际考察并因大小拒绝的记录，不统计所有剩余匹配。如果所有匹配都过大，`items` 为空，但匹配数和省略数仍大于零。可使用 `show`、现有搜索/分页、更窄的查询或更大的允许预算检查省略的数据。空结果不代表用户没有某种偏好，也不能证明某个事实为假。

## 3. 快照、纠正与遗忘

匹配、记录内容、排序和事件 `watermark` 在同一个 SQLite 事务内读取。有界存储最多保留 1,000 条记录；超出时召回会拒绝，而不是静默进行无界扫描。不新增持久检索缓存、提取摘要、派生索引、数据库 schema 或迁移。

每条返回记录包括 ID、当前 revision、内容、主题、最近编辑路径、会话引用和时间戳。`explicit_local_operator` 与 `activated_session_model` 只是路径标签，不是经过验证的原始作者或来源消息引用。召回文字是数据，不是指令、审批或权限。不会自动解决冲突或认证事实。

后续召回会看到已提交的纠正，并排除已终结遗忘的记录。重放历史变更回执不会恢复已遗忘内容。响应是单次读取快照的观测，事务结束后可能已经成为历史；`watermark` 是元数据，不是可复用的快照令牌或授权。遗忘无法撤回已经返回的响应、现有模型上下文、正常宿主历史、备份或导出。不承诺更强的并发交付或全局擦除保证。

## 4. 后端与验证边界

本地后端在 `explicit_records` 和 `literal_search` 之外声明可选的 `bounded_recall` 能力。`MemoryService` 在调用后端前要求三者齐备，校验操作专属字段，并执行协商后的查询/分页限制。旧后端或能力较少的后端若不支持此项，会返回 `capability_unavailable`，不会退回无界列表或通过多次调用拼接不一致结果。现有描述符 API 和存储 schema 版本不变。

离线测试覆盖严格的类型/边界、字面/中文匹配、排序及同分顺序、完整记录省略、精确序列化预算、来源标签、重开/纠正/遗忘/回执重放、后端能力拒绝和原生准入。原生契约运行真实固定版本的 slash 分发器和模型工具注册表，并通过四个独立且禁止网络连接的进程验证召回、纠正和遗忘。这些是确定性的合成数据测试，没有真实模型或 socket listener，不能认证已配置模型的关键词选择，也不等于 Gateway 传输端到端验收。E2.7 新增有界显式召回，自动生命周期集成及 E2.8 仍未完成。
