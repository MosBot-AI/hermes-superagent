# 46. 原生会话任务聚焦

简体中文 | [English](46-native-task-focus.md)

## 1. 已可使用的能力

显式聚焦把一条已保存任务接入接下来的原生对话轮次。选定任务后，主代理在每轮开始时收到它的最新修订、标题、项目标签、到期日期、已记录进度和有界详情。你可以直接说“帮我推进下一步”，不必再次复制任务记录。聚焦本身不会启动 worker、改变任务状态、授予外部操作权限或增加一次模型请求。

这扩展了现有[会话任务工具](29-session-scoped-task-tools-zh.md)，不是记忆提供器。它复用可信单用户、原生进程内 CLI/TUI/Desktop 的支持范围和精确会话/路由激活。任务标签不是原生 Project，也不是权限范围。默认只读加载不注册聚焦钩子。

## 2. 使用已有任务

按照[29](29-session-scoped-task-tools-zh.md)在符合条件的隔离测试 profile 中开启 `mode: local_tasks`、`local_conversation: true` 和 `local_model_tools: true`。保留现有提供器、隔离及其他设置。在该原生会话中执行：

```text
/personal-tasks list
/personal-tools enable-read
/personal-tools focus <列表返回的精确任务ID>
帮我判断这个任务接下来该做什么。
/personal-tools status
/personal-tools clear-focus
```

占位符必须替换为实际返回的任务 UUID。选择要求读或写激活仍有效、任务确实存在；ID 无效或任务不存在时，原有选择不变。状态查询只显示选中的 ID，不读取任务正文。清除聚焦后任务工具仍可使用。`/personal-tools disable` 同时撤销未来任务工具准入和未来聚焦快照。

如需明确要求的本地编辑，先使用 `/personal-tools enable-write`。聚焦不会自行开启写权限。现有模型工具仍要求精确任务 ID、当前修订及稳定重试键。选择另一条任务只替换本会话的聚焦。不会附带关联任务、完整 profile、对话记录或记忆记录。

## 3. 新鲜度与预算

每个获准轮次开始时，钩子重新读取存储，包括任务被编辑、阻塞、完成或取消之后。同一轮内各次模型/工具调用之间不会自动刷新：编辑前使用 `personal_tasks_read`，发生修订冲突时先核对。已完成/取消任务保留历史进度字段，这些字段不证明当前有 worker 在执行。任务和记忆正文不能选择聚焦或授予权限。

完整序列化上下文连同来源/警告前缀不超过 12,000 个 ASCII 字符。保留标识、修订和状态；进度说明优先于较长背景详情。放不下的可选字段会整项省略并列入 `omitted_fields`，不会悄悄截断。模型可通过已有 `show` 操作按需读取。这是字符预算，不是 token 或账单保证；仍适用已配置模型的普通上下文费用。

准入后若存储读取失败，下一段上下文会提示刷新失败，不泄露旧正文、异常详情或路径。不支持或未激活的会话不获得聚焦上下文。普通对话可以继续；任务聚焦不是其他 Hermes 工具的权限强制层。

## 4. 生命周期与隐私

聚焦只存在于当前进程，最长不超过已有的 30 分钟任务激活。刷新尚未到期的激活保留聚焦；到期后重新激活不会恢复旧选择。清除、禁用、卸载、重载、进程重启或已观察到的配置/profile 失效会移除选择。清除和激活变更与已准入读取共用锁：先获准的快照仍可能进入当前轮次，但未来准入会停止。

钩子通过 Hermes 原生 `pre_llm_call` 路径提供面向 API 的用户上下文，不修改系统提示词、不重写过去轮次。宿主可能为提示缓存重放而在历史/sidecar 中保留曾发送的上下文。清除聚焦、到期和任务更正不会删除已有模型上下文、历史或备份。与任务工具一致，选定会话内所有获准控制者和模型活动共享这些数据；这不是独立的所有者认证。

委派子代理、cron、消息平台、其他 profile/会话/路由、缺少有效轮次、托管 worker 和隔离插件宿主不会因此获得聚焦访问。不要为使用此功能关闭隔离。插件不选择提供器/模型，也不占用原生记忆提供器槽位。

## 5. 证据与剩余验收

单测覆盖新修订、完整字段预算、Unicode 转义、无效选择、精确会话范围、到期后重启用、清除/禁用、配置变化、存储失败以及准入/清除顺序。固定宿主契约覆盖真实插件注册、斜杠命令授权、原生轮次/路由上下文、宿主钩子收集和 API 内容拼装，以及子代理/cron 排除和卸载/重载。测试只用合成数据和临时 profile，并阻断网络连接；不启动 Gateway socket、不调用模型。
